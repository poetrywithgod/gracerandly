# Sign-in screen photos

Drop photos here (`.jpg`, `.jpeg`, `.png` or `.webp`, about 1600 x 1200 px, under 500 KB each is
plenty) and restart the API. The admin sign-in screen then shows them, in file-name order, in
place of the built-in illustrations, changing every 4 seconds. Name them `1-...`, `2-...` to
control the order. Use photos you own or have a licence for.
